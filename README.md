# TaskFlow

> Application web de gestion de tâches collaborative - Projet L2 Génie Logiciel, Groupe ISI Dakar 2026

---

## Description

**TaskFlow** est une application web permettant de planifier, assigner et suivre des tâches en équipe, en temps réel. Simple, claire et efficace, elle répond aux besoins des équipes académiques et professionnelles qui cherchent à mieux organiser leur travail.

Ce projet a été réalisé dans le cadre de l'**atelier créatif du module L2 Génie Logiciel** au Groupe ISI de Dakar.

---

## Fonctionnalités

-  **Tableau de bord personnalisé** - vue d'ensemble de toutes les tâches
-  **Gestion des priorités** - haute, normale, basse
-  **Deadlines et rappels** - alertes avant échéance
-  **Espace collaboratif** - assignation et suivi par membre
-  **Authentification sécurisée** - inscription, connexion, profil
-  **Suivi de l'avancement** - indicateurs visuels de progression
